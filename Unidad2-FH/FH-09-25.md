### No sé, algo de la base de datos

En el archivo settings.py, hay que indicar ciertos datos de la base de datos creada en wampserver.

```
DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.mysql',
        'NAME': 'fitness_db',
        'USER': 'Fitness',
        'PASSWORD': 'fit12345',
        'HOST': 'localhost',
        'PORT': '3306',
    }
}
```

> [!NOTE]
> Lo de la contraseña ta mal, debería estar encriptada, la contraseña nunca va en el código.

1. Se crea un archivo .env para la contraseña. Es un archivo específico para guardar contenido sensible.

2. Se instala la librería decouple, es la librería encargada de los archivos .env.

```
pip install python-decouple
```

3. Hay que importar una cosa en el settings.py

```
from decouple import config
```

4. Entonces, en el mismo settings.py, las credenciales se cambian a las siguientes:

```
DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.mysql',
        'NAME': config('NAME'),
        'USER': config('USER'),
        'PASSWORD': config('PASSWORD'),
        'HOST': config('HOST'),
        'PORT': config('PORT'),
    }
}
```

## Para la base de datos

1. Crear la base de datos en el WAMPSERVER, con MySQL.
```
CREATE DATABASE fitness_bd;
```

2. Crear un usuario.
```
CREATE USER 'Fitness'@'%' IDENTIFIED BY 'fit12345';
```

- EL primero es el usuario, luego el arroba necesario, y luego se puede añadir un comodin (para conectarse al servidor de cualquier lado, sirve para usuarios remotos).
- Debe ser identificado con una contraseña.

3. Asignar permisos al usuario.
```
GRANT ALL PRIVILEGES ON fitness_bd.* TO 'Fitness'@'%';
```

- Conceder todos los privilegios en la base de datos 'fitness_bd' al usuario "Fitness".

4. Grabar privilegios, o sea el commit.
```
FLUSH PRIVILEGES;
```

> [!NOTE] 
> De partida hay que bloquear el usuario ROOT, nadie puede trabajar con él por temas de seguridad.
> Para tener esos privilegios, hay que crear un usuario en específico.
